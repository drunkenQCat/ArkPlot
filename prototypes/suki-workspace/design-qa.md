# ArkPlot 原型 → Avalonia 设计核对

final result: passed

本次范围：已确认的主界面，以及随后制作的设置、运行日志原型。依据用户要求，原生版本保留 SukiUI 6.0.3 的主题、组件渲染与系统窗口装饰，不将 HTML 的控件样式逐像素覆盖到 SukiUI。

## 证据

- 原型：`index.html`、`settings.html`、`logs.html`；Chromium 实际渲染与交互验证。
- 原生：`native/01-generation-plan.png`、`native/02-model-settings.png`、`native/04-workflow-logs.png`，另有深色及设置各分类截图；由生产 App + Skia + Avalonia Headless 实际渲染。
- 同屏对照：`comparison-main.png`、`comparison-settings.png`、`comparison-logs.png`；`qa-compare.html` 可查看完整对照。
- 原生窗口尺寸分别为 1040×850、1020×830、1000×780。HTML 自适应内容高度，原生固定窗口使用内部滚动；对照按相近宽度呈现，不据此声称逐像素一致。测试章节、模型与原型示例值不同，模型连接未伪装成已验证。

## 已发现并修复

1. **P1 / 图标缺失**：原生 Material 图标缺少样式注册。加入 MaterialIconStyles，重新渲染确认。
2. **P1 / 设置内容未显示**：隐藏标签栏后缺少 ItemsPresenter。保留不可交互的零高 presenter，五个分类均已实际渲染。
3. **P2 / 按钮层级**：SukiUI 的 Flat 是实心按钮；次要操作改用 Basic，唯一主操作使用 Flat Rounded。
4. **P2 / 设置开关布局**：默认 Content 排在开关上方，使页面超长。改为说明在左、开关在右，保持原生 ToggleSwitch。
5. **P2 / 深色日志底色**：移除旧日志行与容器的白底、固定蓝灰底，使用动态主题资源；阶段图标和选中文字使用主题提供的深色适配色。
6. **P2 / 日志透明度**：支持全部阶段、全局错误筛选、暂停跟随；含错误的已结束阶段显示“有错误”，清空日志同步清理错误汇总。
7. **P2 / 日志阅读层级**：级别英文缩写改为 Material 图标，正文使用正常 UI 字体，保留时间列及可展开详情入口。

## 五个核对面

- **字体与文字**：使用项目原有 SukiUI 字体与字重；HTML 使用系统字体。标题层级、正文和辅助信息明确，标签与主要操作无裁切。原生抗锯齿和部分默认字重差异属于平台渲染差异。
- **间距与布局**：保留 banner、分类、左右卡片、底部路径结构；设置左侧分类与右侧卡片、日志左右分栏对应原型。固定窗口中详细内容可滚动，设置保存区固定可见。
- **颜色与主题**：保持 App 的 Blue 配色；实际使用 GlassCard、Chips、ToggleSwitch、Expander、SukiWindow、SukiToast 及原生菜单。原生深色背景由现有 SukiWindow 绘制，未用 HTML 的灰色背景覆盖。
- **素材与图标**：使用原 `slogan.jpg`，顶部裁切保留标志和人物头部；图标来自 Material Design Icons。没有替换为新绘制的 banner。
- **文案与功能**：保留真实剧情类别“插曲 / 故事集 / 主题曲”、现有模型名称及配置字段；去掉宣传式标题。记录保留复盘、图片详情、导出、开发缓存清理等原有入口。
