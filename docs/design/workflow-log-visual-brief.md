# Workflow 阶段性日志面板 — 视觉概括

> 用途：给有识图能力的 Agent 参考，将本概括 + 草图转化为一段可交互 HTML 原型。
> 目标：把「纯文本日志流」升级为「阶段驱动的垂直时间线」，让用户一眼看清整个生成流程走到哪一步、每个阶段的结果如何。

## 一、整体形态

整体是一个**垂直工作流时间线**（stepper / milestone 样式），从上到下依次排列当前任务的各个**阶段（stage）**。左侧是阶段节点列，右侧是每个阶段的**详情日志区**。整个面板视觉上像一条「进度轨道」，而非一坨文字。

表达式统一为：

```
[轨道线]  ●阶段节点   阶段标题 + 状态徽章 + 耗时
            │          └─ 阶段内日志（可展开）
[轨道线]  ●阶段节点   ...
```

## 二、阶段节点（Time 轴核心）

每个阶段是一个节点，节点是**圆点/菱形图标**，圆点之间用一条**垂直连线**串起来，形成轨道。轨道线本身有进度感——已完成段的连线是实心高亮，未完成段是虚线/暗色。

圆点图标按状态变化：

| 状态 | 视觉表现 |
|------|----------|
| 未开始（pending） | 灰色空心圆，等待态 |
| 进行中（active） | 高亮色实心圆 + **呼吸/脉冲动画**（光晕扩散），右侧显示当前阶段简短动效文案 |
| 成功（done） | 绿色实心圆 + **对勾 ✓**，完成后弹出微动画 |
| 失败（failed） | 红色实心圆 + **叉 ✗**，节点轻微抖动或泛红脉冲 |

每个阶段标题右侧放一个**状态徽章**（小圆点/文字标签：进行中 / 完成 / 失败），以及**该阶段耗时**（如 `203ms`）。

## 三、阶段内日志详情

每个阶段下方有自己的日志区，**默认展开**（或点击节点展开/收起）。日志区内容：

- 缩进在阶段节点之下，与标题对齐，形成「这个阶段发生了什么」的从属关系
- 每条日志带**时间戳**（`HH:mm:ss`）和**级别着色**：
  - `[Info]` 灰白
  - `[Progress]` 蓝色（可配行内小进度条）
  - `[Success]` 绿色
  - `[Warn]` 黄色
  - `[Error]` 红色 + 加粗 + 底纹
- 新日志**逐条滑入**（淡入 + 上移），不打断阅读
- 进行中的阶段日志区底部有一个**闪烁的光标/省略号**，表示还在产出

## 四、整体进度

面板顶部（或侧边）放一个**总进度**：`已进行 阶段 2/5` 或一个细进度条 + 百分比。进行中阶段切换时，进度条平滑推进。

## 五、错误与交互

- 任一阶段失败：该节点变红，其日志自动展开，错误行高亮在最前，并出现一个「定位到问题」的提示按钮（示意即可，无需真实跳转）
- 点击任意阶段节点可在「展开/收起」该阶段日志间切换
- 面板顶部工具栏：**仅显示错误**切换、**清空**、**导出**（示意按钮即可）
- 全部完成时：最末节点下方出现一个绿色「全部完成」横幅，带一次轻微弹入动画

## 六、可替换的占位

阶段名称是**占位符**，实际会替换为真实 pipeline 阶段（示例：下载剧情 → 解析 → 导出 Markdown/HTML → 附加处理 → 完成）。Agent 在 HTML 中优先用可读的中文占位名即可。
